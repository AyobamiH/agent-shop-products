# Calibration cases

- UI says “owner action” while the canonical warning says automatic recovery: repair the projection and add a meaningful drift case.
- A nullable measurement is absent: display its documented unknown state, not a healthy zero.
- An optional integration is disabled: apply its documented semantics rather than a generic failure banner.
- A hand-edited generated page differs from its source: fail the check and edit the semantic authority first.
- A dashboard cache says permission is valid: reread consequence-time authority before a write.
- A snapshot budget passes on 5,000 fixture rows: report the console fixture scope, not provider publication throughput.
