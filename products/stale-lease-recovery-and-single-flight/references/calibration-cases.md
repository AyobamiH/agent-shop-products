# Calibration cases

- Parent is running, attempt expired, executor absent and effect ledger proves none: consider targeted canonical recovery after current authority and child checks.
- Lease expired but provider receipt is ambiguous: reconcile the consequence first; do not terminalise or retry blindly.
- Equivalent run has a live owned attempt: exact ingress handling precedes coalescing into that run.
- Equivalent run failed yesterday: allow today's eligible natural tick.
- Same graph and task in a different lane: keep admissions distinct.
- Recovery passed a forced test: require an ordinary scheduled cycle before claiming natural cadence acceptance.
