# Calibration cases

These cases exercise reasoning. They are not evidence of production execution.

| Input evidence | Required conclusion | Next useful check |
| --- | --- | --- |
| Six skills are listed; provider draft discovers 21 tools; no corresponding session tool is exposed | Skills are advertised and provider discovery succeeded; callable session integration is unestablished | Verify the intended installation and supported connection path |
| Public owner connection succeeds for one synthetic brief | That account and basic workflow passed | Test fresh-account installation separately if required |
| Output is schema-valid but omitted services produce a standalone zero | Transport and schema passed; semantic acceptance failed | Reproduce omitted and explicitly empty input, preserve red/green revisions |
| Review branch has green CI; production serves the earlier revision | Candidate is tested; production repair is pending | Satisfy the repository gate and verify deployment after merge |
| 94 cloud entries and 88 executor entries contain 109 distinct names | 182 surface entries, 109 names | Retain both surfaces and verify deduplication |
| A forbidden tool is present in the registry | Metadata exposure is recorded; execution remains excluded | Use an authorised alternative if it can satisfy the task |

Reject a handover that collapses these into “everything is ready”.
