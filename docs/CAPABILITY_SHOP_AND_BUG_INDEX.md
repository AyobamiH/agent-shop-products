The 9 October 2026 owner instruction expands Shop discovery to every advertised external skill, tool and orchestration control, alongside the original product catalogue. The canonical session inventory supplies **111 external skills, 868 tools and 11 controls: 990 listings**. The original 33 products remain a separate authoring and ownership record.

Each external listing has a stable kind/name identifier, provider or surface metadata, a detail page and an original integration brief. The buyer can take the brief to the existing Tail Wagging custom-work handoff. Work is quote-first and subject to feasibility and agreed scope. No provider account, privileged runtime access, third-party implementation or unestablished redistribution right is offered for sale. No POST request is executed by the catalogue.

`catalog/capability-inventory.json` remains the exact names-only capture. `catalog/capability-acquisition.json` owns the shared procurement policy. Frontend copies are generated, parsed once and validated. Search, kind/provider filters and pagination use the same deterministic query model in HTML and JSON. GET briefs contain a request template plus explicit missing buyer inputs; they are not accepted jobs or payment receipts.

Its original eleven tabs and records are preserved. The public sanitised seed lives in `catalog/agentic-coding-bugs.json`; it contains no private workbook URL, transcript, customer data or credentials.

The first 18 entries capture documented failure modes and preventive checks. Historical reports, public implementation review and open candidate repairs have separate evidence states. None is labelled freshly reproduced by this indexing pass. Stable bug/evidence IDs permit later attempts, revalidation and supersession without overwriting earlier evidence.
