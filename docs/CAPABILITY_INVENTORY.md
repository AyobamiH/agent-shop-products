## Execution and publication boundaries

Advertised metadata does not establish connection, granted authority, successful execution, publication or customer availability. A missing executor root warning also does not establish that the capability is installed or operational.

External skill bodies, privileged tool schemas, account and plugin identifiers, credentials, private examples and host paths are excluded. The inventory records names and surfaces only.

The owner excludes RUBE/RBE from execution and uses the native LinkedIn composer for the reviewed campaign. Registry presence does not override those restrictions. Cloudflare work uses supported APIs/CLI rather than browser access; the extraction introduces no API billing authority.

The shop remains CLI-first. Reading the Sites MCP workflow and using retrieval connectors does not create an Agent Shop MCP server. The [coverage record](SKILL_COVERAGE.md) identifies the few named dependencies actually observed in this review; it does not claim all 111 skills were invoked.
